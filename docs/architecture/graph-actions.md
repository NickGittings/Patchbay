### Graph actions

`actions.rs` — groups (`Project.groups`) and terminal roles (`TerminalSpec.action`) drive `ActionPlan` (start a group's development tasks in startup stages, or validate the components a change may affect) and `GraphActions` (one coordinated operation at a time; environments owned per project, group and task). They run inside the session service (`Request::ActionRun`/`ActionStopGroup`/`ActionCancel`) through the `Terminals` trait, so their terminals are ordinary recorded sessions; the adapter's `graph_action_*` commands only trust, restrict and move the project into the task's worktree first. Results and the busy state land in the project they ran for (`patchProject`, `lib/actions.ts`). Validators run one at a time, each stopped and failed (`TaskResult.message` ↔ `ActionReport` `message`) once it outlives the validation deadline (`VALIDATION_TIMEOUT`, 30 min; `GraphActions::with_validation_timeout`), so a watch mode can't block `agent validate` or Auto forever; development terminals have only their readiness timeout. The UI calls groups **stacks**: the rail's Stack panel (`components/StackPanel.tsx`) edits, starts and stops them, shows each member's Development terminals, and offers dev-server terminals of components without one (`lib/stack.ts` `stackSetup`: serving or watching commands and dev/serve/start/watch ids, never checks or test watchers (`validators.ts` `checkLike`), with a ready text guessed for known servers; all start ticked; Create stack also creates "Local stack" when none exists, ordered when members are linked; Dismiss stores `stackDeclined` in the workspace layout). "Detect stack with an agent…" runs `stack_proposals.rs` (below). Detectors never assign roles; the Activity panel (reached from `RunSelect`'s "Set up validation…" while suggestions remain) offers to mark unassigned check terminals of components without a validator as Validation (`lib/validators.ts`: `validatorSetup` in one pass, readings cached per `TerminalSpec` object), an ordinary map edit. Suggestions are approximate and none starts checked: a check id (`test`/`check`/`lint`…) or a known check program or package script/make target (first `:._-` segment), leaving out anything that obviously watches or serves (watch flags not set false, dev/serve/start/preview/watch scripts or subcommands, bare dev servers or `vitest`, a backgrounded `&`). Only Dismiss declines (`validatorDeclined`, pruned of removed terminals on each decline, restorable from the panel); workspace layout, never `patchbay.json` or `dirty`. The "No check terminal" line appears only beside suggestions.
